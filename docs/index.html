A transparent data journey

Public REST API→Airflow validation→PostgreSQL marts→BI snapshot

This viewer uses an exported PostgreSQL mart snapshot. The Airflow DAG refreshes it after each successful warehouse load. The report month reflects source availability, not today’s date. Negative reported net measures are preserved and flagged for review. Missing measures stay missing; missing field-month records are never assumed to be zero.

Operator is the current field operator, applied to historical records for exploration. Volumes are reported field production, not operator equity production, reserves, revenue or profit. No forecast is shown. Source: Norwegian Offshore Directorate · NLOD open-data licence.
